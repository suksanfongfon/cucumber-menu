# 🥒 Cucumber Menu / เมนูแตงร้าน

A bilingual (Thai/English) collection of dishes that feature cucumber as an ingredient — from Thai cuisine to international classics, drinks, pickles, and cocktails.

## Live site

After enabling GitHub Pages (Settings → Pages → Branch: `main` / Folder: `/`), your site will be live at:

```
https://<your-username>.github.io/<repo-name>/
```

## What's inside

- **`index.html`** — the static, single-file website (no build step)
- **`data.json`** — menu data consumed by the site (84+ dishes)
- **`Cucumber_Menu.xlsx`** — the source spreadsheet

## Updating

Re-run the scheduled task in Cowork (every 1 hour) and it will append new dishes to the spreadsheet and regenerate `data.json` + the site.

## Tech

Plain HTML/CSS/JS — no framework, no dependencies. Mobile responsive, accessible, and fast.
